文献阅读系列

  • Three-dimensional phase field microelasticity theory and modeling of multiple cracks and voids :

    讲了 Khachaturyan 的弹性力学理论在三维相场模拟中的应用

  • A multiphase field model: sharp interface asymptotics and numerical simulations of moving phase boundaries and multijunctions :

    Britta Nestler 关于界面能的一些工作，基于反对称形式的界面能构造进行了一些分析。

  • Anisotropic multi-phase-field model: Interfaces and junctions :

    Britta Nestler 关于界面能的一些工作，在多相场模型与 Cahn-Hoffman $\xi$ 向量的基础上进行了扩展。

  • Phase field microelasticity theory and modeling of elastically and structurally inhomogeneous solid :

    Khachaturyan 相场微弹性理论更详细的阐述。

相场模拟，但是用很多语言 I

  • CPP_impl_v1.cpp : 调幅分解的 C++ 基础实现
  • CPP_impl_v2.cpp : 调幅分解的 C++ 实现，使用了更多的 C++ 特性

相场模拟，但是用很多语言 II

  • PY_impl_v1.py : 调幅分解的 Python 基础实现
  • PY_impl_v2.py : 使用了 Numpy 提供的数组
  • PY_impl_v3.py : 广泛使用了 Numpy 内置的方法，提高计算效率
  • PY_impl_v4.py : 使用了 Python 的 matplotlib 库用于可视化

相场模拟，但是用很多语言 III

  • JS_impl_v1.js : 调幅分解的 JavaScript 基础实现
  • JS_impl_v2.js : 使用面向对象与 Stride 重写求解逻辑
  • JS_impl_v3.7z : 分文件实现并允许使用输入文件，是 7z 压缩包
  • TS_impl_v1.ts : 使用 TypeScript 实现了 JS_impl_v3 的代码
  • TS_impl_v2.7z : 进一步使用 React 图形库实现浏览器端的可视化，是一份小压缩包。

  • C_my_fft_test_main.c : 用来测试快速傅里叶算法的可执行文件，可以编译执行
  • C_my_fft.c : 自己实现的快速傅里叶变换算法源文件，可以编译成静态库
